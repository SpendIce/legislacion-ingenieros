# Legislación para Ingenieros — Repaso y práctica

Material de estudio personal (FIE, 4.º año): doce lecciones
interactivas, glosario y pares de conceptos que se confunden.
Sitio estático para repasar desde el celular.

Las ediciones viven en un workspace local privado. Las citas a
diapositivas y apuntes de la cátedra figuran como texto: ese material
original no se publica acá. Los links a la normativa vigente (Infoleg)
sí funcionan.
